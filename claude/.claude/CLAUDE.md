# CLAUDE.md

Whenever you are working on a project in ~/code/, please align with the
following guidelines:

## Repository-level AGENTS.md and CLAUDE.md files

The role of any repository-level `AGENTS.md` or `CLAUDE.md` file is to describe
common mistakes and confusion points that agents might encounter as they work on
this project. If you ever encounter something in the project that surprises you,
please alert the developer working with you and indicate that this is the case
in the `AGENTS.md` or `CLAUDE.md` file to help prevent future agents from having
the same issue.
